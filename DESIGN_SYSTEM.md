# Design System

## Palette
- Ice White `#F8FBFF`
- Electric Ice `#DFF7FF`
- Electric Blue `#1677FF`
- Electric Cyan `#00C9D8`
- Midnight Navy `#182B45`
- Silver Mist `#E9EFF7`

Mostly light surfaces; blue for primary actions; cyan as a restrained accent; navy for selective contrast. Avoid an all-dark look.

## Style
Premium technology-founder portfolio, editorial hierarchy, generous whitespace, deliberate grid, clean typography, polished imagery, selective glassmorphism. Avoid generic SaaS templates, excessive neon, gaming HUDs and cyberpunk styling.

## Hero
Use supplied rooftop portrait as primary real-person image. Pair with a refined 3D environment, name, BOYS MSG identity, professional positioning and clear CTAs. Intro must be skippable.

## Motion / 3D
Use motion to guide attention, not distract. No scroll hijacking. Lazy-load heavy 3D and provide static fallback. Respect `prefers-reduced-motion`. Avoid expensive continuous effects on mobile.

## Accessibility
Semantic landmarks, logical headings, keyboard navigation, visible focus, adequate contrast, meaningful alt text, reduced-motion support, labeled forms.

## Responsive
Design mobile deliberately, not as a compressed desktop. Hero, portrait, nav, cards and 3D fallback must work on narrow screens.
